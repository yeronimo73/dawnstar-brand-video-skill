# 캐릭터 말하기: 목·어깨 움직임 계산

그림 한 장짜리 캐릭터를 코드로 말하게 하는 방법이다. 던스타 캐릭터 민호로 다섯 판을 거쳐 "좋아, 자연스럽다"를 들은 계산을 정리했다.

핵심 한 줄: 입, 눈, 팔은 그린 그림을 바꿔 끼우고, 머리는 휘지 않는 강체로 기울이고, 목에서 가슴까지는 가중치를 줄여 가며 이어 붙인다.

## 1. 다섯 판의 기록

| 판 | 방식 | 받은 말 | 원인 |
|---|---|---|---|
| 처음 | 머리 주변 타원을 통째로 휘게(remap) | "목을 나누어서 움직이는 것 같은 형상" | 경계가 목에 걸려 목과 옷깃이 늘어나고 비틀림 |
| 2판 | 턱선에서 머리를 떼어 강체로 이동·회전 | "목이 떨어져서 놀아." (팔은 괜찮다고 함) | 머리만 옆으로 미끄러지고 목은 고정 |
| 3판 | 턱에서 옷깃까지 띠만 머리와 몸 사이로 늘림 | "어깨부터 목까지 굴곡에 따라 계산을 잘 해서" | 띠만 늘어나 목이 꺾여 보임 |
| 4판 | 턱 -> 옷깃 -> 어깨 -> 가슴 연쇄 가중치 | (자료를 찾아보라는 지시) | |
| 5판 | 4판 + 몸 전체를 허리 축으로 회전(머리 회전의 22%, 3프레임 지연) + 아래 가장자리 복제 채움 | "좋아 자연스럽다" | |

이 판들 전에 코덱스(다른 AI)에게 렌더러 전체를 맡겼던 첫 영상은 "정말 못 봐줄 정도"였다. 측정과 그림 생성은 맡길 수 있어도, 움직임 설계는 직접 해야 했다.

바꾸지 말 것 (지적받아 정한 값):
- 머리를 옆으로 옮기는 이동(dx) 금지. "목이 떨어져서 놀아."
- 머리 주변을 통째로 휘게 하는 방식 금지.
- 목 띠만 늘리는 방식 금지.
- 팔·표정은 코드 관절로 돌리지 않는다. 그린 그림을 통째로 바꿔 끼운다. 팔 사슬 휘기, 손목 회전, 손가락만 교체, 팔만 오려 붙이기는 모두 "손가락 어색", "어깨 분리"로 퇴짜였다.

## 2. 준비하는 그림

| 종류 | 장수 | 내용 |
|---|---|---|
| 기준 그림 | 1 | 허리 위 정면, 입 다문 얼굴, 손은 아래 |
| 입 | 6 (작게, 아, 오, 이, 미소 등) | 얼굴 전체를 다시 그린 그림 중 입 부분만 차이 마스크로 따서 부드럽게 붙임 |
| 눈 | 3 | 반쯤 감김, 감음, 웃는 눈 |
| 팔 자세 | 4 | 반쯤 올린 손(전환용), 손 펴기, 가슴에 손, 두 손 펴기 |

그림을 바꿀 때 겹침(크로스페이드)은 없다. 한 번에 바꿔 끼운다. 자세가 바뀔 때만 반쯤 올린 손을 3프레임 끼운다.

## 3. 층 구성

1. 머리 층: 턱선 바깥 윤곽에서 6px 아래까지를 자른다. 휘지 않는 강체다. 턱선 좌표는 자동 검출이 입술 선을 턱으로 잡아 실패해서 손으로 찍는다.
2. 몸 층: 기준 그림(또는 자세 그림)에서 머리를 지운 것. 머리가 움직일 때 드러나는 턱 밑만 목 피부색으로 채운다. 넓게 채우면 턱 옆에 살색 네모가 보인다.
3. 자세 그림에 원래 그려진 머리·목이 새어 나오면, 머리 자리를 지운 테두리 고리를 기준 그림의 목으로 채운다.

## 4. 움직임 계층 (몸 회전 안에 머리 회전)

Live2D 같은 리깅의 구조를 따른다. 몸이 허리 축으로 조금 돌고, 그 안에서 머리가 목 밑동을 축으로 돈다. 30fps 기준.

```
rot      = 1.5*sin(2*pi*0.19*t + 0.5) + 0.6*sin(2*pi*0.47*t + 1.3)      # 머리 기울기(도), 천천히 흔들리는 두 파형
body_rot = 0.22 * rot (3프레임 늦게)                                     # 몸은 머리의 22%만, 살짝 늦게
몸   B  = 숨쉬기(세로 0.35%, 3.6초 주기, 아래 기준) x 회전(body_rot, 축 = 허리)
머리 Hm = B x 회전(rot - body_rot, 축 = 목 밑동) + 끄덕임 dy
```

값 요약:

| 항목 | 값 |
|---|---|
| 머리 기울기 진폭 | 1.5도와 0.6도 두 파형 (주파수 0.19Hz, 0.47Hz) |
| 몸이 따라가는 비율 | 머리의 22% |
| 지연 | 3프레임 (0.1초) |
| 머리 회전 축 | 목 밑동 (그림 1920x1080 기준 960, 335) |
| 몸 회전 축 | 허리 (960, 1250) 처럼 그림 아래쪽 |
| 숨쉬기 | 세로 0.35%, 주기 3.6초 |
| 머리 옆 이동 | 없음 (0) |

끄덕임(머리 세로 이동):

| 때 | 크기 |
|---|---|
| 센 음절 시작 (음량 0.55 이상) | 2px |
| 문장 끝 "다·요" | 3px |
| 자세가 바뀔 때 | 1.5px |

사인 반주기(12~16프레임)로 넣고 가우시안(시그마 2프레임)으로 부드럽게 한다.

```python
for s0, s1, c, w in syllables:                       # 음절 시작 시각
    f = int((s0 + PRE) * FPS)
    if rms[f + 2] > 0.55:                            # 센 음절
```

## 5. 목·어깨 연쇄 가중치

머리가 움직이는 변환을 얼마나 따라가는지를 위치마다 다르게 준다.

| 위치 | 가중치 w |
|---|---|
| 턱 위 (머리) | 1.0 |
| 턱에서 옷깃 | 1.0에서 0.55로 선형 감소 |
| 옷깃에서 어깨선 | 0.55에서 0.20으로 선형 감소 |
| 어깨선에서 가슴 | 0.20에서 0으로 제곱 감소 |
| 가슴 아래 | 0 |
| 가로 방향 | exp(-((x - 중심) / 230)^2) 를 곱함 (어깨 끝은 거의 고정) |

옷깃 선은 포물선 y = 322 - 0.004 (x - 960)^2 로 근사한다. 마지막에 가우시안(시그마 6)으로 가중치를 부드럽게 한다.

몸 층은 다음 식으로 그린다. 각 화소가 어디서 가져올지를 몸 변환과 머리 변환 사이에서 w로 섞는다.

```
map = 몸 역변환 + w * (머리 역변환 - 몸 역변환)
```

```python
def chain_w():
    w = np.zeros((H, W), np.float32)
    w = np.where(yy <= jaw_y, 1.0, w)                                              # 턱 위
    w = np.where((yy > jaw_y) & (yy <= collar_y),                                  # 턱 -> 옷깃
                 1.0 - (1 - collar_w) * (yy - jaw_y) / np.maximum(collar_y - jaw_y, 1), w)
    w = np.where((yy > collar_y) & (yy <= shoulder_y),                             # 옷깃 -> 어깨
                 collar_w - (collar_w - shoulder_w) * (yy - collar_y) / np.maximum(shoulder_y - collar_y, 1), w)
    w = np.where((yy > shoulder_y) & (yy <= chest_y),                              # 어깨 -> 가슴
                 shoulder_w * (1 - (yy - shoulder_y) / (chest_y - shoulder_y)) ** 2, w)
    lateral = np.where(yy <= jaw_y, 1.0, np.exp(-((xx - cx) / 230.0) ** 2))
    return cv2.GaussianBlur((w * lateral).astype(np.float32), (0, 0), 6)
```

설정값(1920x1080 그림 기준): collar_w 0.55, shoulder_w 0.2, shoulder_y 385, chest_y 540, 옷깃 y0 322, 옷깃 곡률 0.004.
허리 회전 때 아래 모서리에 흰 틈이 생기지 않도록 가장자리는 복제로 채운다(BORDER_REPLICATE).

## 6. 입과 눈

- 말소리 인식으로 단어 시각을 얻어 음절로 나눈다. 너무 짧은 단어는 음절당 최소 0.13초로 늘린다.
- 모음별 입: ㅏ는 벌림, ㅗ·ㅜ는 오므림, ㅣ·ㅔ·ㅐ는 이가 보이는 입, ㅓ·ㅡ는 작게. ㅁ·ㅂ·ㅍ 받침은 음절 끝 30%를 닫는다. 음량이 작으면 닫거나 작은 입.
- 1프레임짜리 입 변화는 없앤다(최소 2프레임 유지).
- 깜빡임은 4프레임(반감, 감음, 감음, 반감). 말이 끝나면 웃는 눈과 미소.
- 너무 크게 웃는 입은 과해서 쓰지 않는다.
- 손짓은 문장마다 정해 둔 순서로 바꾼다. 문장 사이가 0.6초 넘게 쉬면 손을 내린다.

## 7. 어디까지가 측정이고 어디부터가 추정인가

- 레퍼런스(코드로 만든 웹툰풍 캐릭터)를 재서 알아낸 것: 머리는 좌우로 약 13px(1280 기준), 기울기 1도 안팎만 움직이고 몸통은 거의 고정이다. 표정은 겹침 없이 교체된다. 조용한 구간의 프레임이 비트 단위로 같다.
- 자료에서 가져온 것: Live2D의 구조(몸 회전 안에 얼굴 회전), 머리 맨 위 관절은 옆으로 약 5.5도만 굽고 대부분은 아래 목뼈에서 일어나므로 회전 중심을 목 밑동에 둔다.
- 추정인 것: 말할 때 기울기 2~4도와 끄덕임 2~5도는 게임 튜토리얼 가이드 값이고, 몸이 머리를 따라가는 비율 15~25%, 지연 2~4프레임도 추정이다. 22%와 3프레임은 그 범위에서 골라 보고 "자연스럽다"를 들은 값이다. 다른 캐릭터에서는 이 범위 안에서 조정해 본다.

## 8. 새 캐릭터에 적용할 때

1. 기준 그림 한 장과 입 6, 눈 3, 팔 자세 4장을 같은 화풍으로 준비한다.
2. 턱선(귀 아래에서 턱 끝, 반대쪽 귀 아래까지), 턱 안쪽 폭, 옷깃 윗선, 목 밑동, 허리 축을 그림 위에서 손으로 잰다.
3. 짧은 대사로 렌더해서 목 둘레를 확대해 본다: 목이 떨어지는지, 턱 옆에 틈이나 살색 네모가 있는지, 입 아래 세로 줄무늬가 있는지, 자세가 바뀔 때 튀는지.
