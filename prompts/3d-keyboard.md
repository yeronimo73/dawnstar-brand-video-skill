# 카드가 바닥에 눕더니 3D 키보드로 바뀌는 영상

## 참고 영상
인스타그램 제작자 계정 miftahul_islam_efaz, 게시물 ID DeH5WTZgSmX. 1080x1920, 60fps, 22.1초, 음악 없이 효과음만.
2D UI 카드를 하나씩 보여 주다가 카드가 눕고, 카메라가 날아 3D 키보드로 들어가 키를 누르는 영상.

## 실제 지시와 피드백
| 판 | 한 일 | 받은 말 |
|---|---|---|
| 시작 | 링크를 건네며 재현을 요청 (정확한 문장은 확인 못 함) | |
| 앞 판 | 키 눌림을 원본에서 비슷하게 잰 값으로 넣음(깊이 0.28, 0.09초) | "입력되는 모션이 없네." (이 문장이 나온 정확한 판 번호는 기록에서 확인 못 함. 기록에는 "키 눌림이 안 보임, 던스타 지적"으로 남아 있음) |
| 고친 판 | 깊이 0.62, 내려가는 시간 0.05초, 유지 뒤 0.17초 스프링 복귀 | (다음 판으로 진행) |
| 효과음 | 원본 효과음을 따라 비슷한 소리를 넣음 | 휙, 톡, 띠링, 총소리 같은 소리를 엄청 싫어한다고 해서 부드러운 swell, riser, 작은 클릭만 남김 |
| 렌더 방식 | | 빠른 렌더(EEVEE)로 구조를 검수한 뒤 최종만 가장 좋은 품질(Cycles)로 |

## 측정 숫자
| 항목 | 값 |
|---|---|
| 구간 | 0~1.4초 펼침 / 1.4~13.3초 2D 카메라가 UI를 하나씩 / 13.3~15.5초 카드를 눕히고 층을 띄움 / 15.5~16.9초 카메라가 날아 3D로 / 16.9~21.7초 키 눌림과 화면 타이핑 / 21.7초 사라짐 |
| 눕힌 카드 각도 | rotateX 49도, rotateZ -27도 |
| 팬(카메라 이동) | 0.5초, expo.inOut |
| 글자 간격 | MOTION 여섯 글자가 17.55~18.74초 사이 |
| 키 눌림 | 고치기 전: 깊이 0.28, 0.09초. 고친 뒤: 깊이 0.62, 내려감 0.05초, 유지, 0.17초 스프링 복귀 (깊이는 모델 단위) |
| 카메라 맞춤 | 레퍼런스 화면의 키캡 6개 중심과 뚜껑 화면 네 모서리 좌표에 좌표 하강법. 변수는 카메라 위치·회전에 더해 본체 회전과 뚜껑 각도까지 |
| 렌더 시간 | EEVEE 약 1초/장, Cycles 약 8.5초/장 (400프레임 약 1시간) |

## 작업 순서
1. 60fps 전 프레임과 접촉표로 구간을 나눈다. 효과음 시작점을 재서 팬·클릭·완성 시점을 맞춘다. 소리가 움직임의 박자다.
2. 장치를 숫자로 적는다. "비슷하게"가 아니라 회전 각도, 펼침 키프레임, 팬 길이를 숫자로.
3. 도구를 장면별로 나눈다. 글자·카드·카메라 확대는 HTML + GSAP, 평면 카드가 눕는 장면은 CSS 3D, 진짜 물건은 블렌더. 블렌더로 글자 UI를 만들면 흐리고, HTML로 물건을 만들면 입체감이 안 난다.
4. 3D는 카메라부터 맞춘다. 처음 맞춤이 나빴을 때 본체 회전과 뚜껑 각도도 변수로 넣자 맞았다.
5. 케이블처럼 모양이 자유로운 것은 레퍼런스 화면 좌표를 바닥 평면으로 역투영해 3D 경로로 만든다.
6. 두 장면 이음: HTML 카드를 확대하며 투명하게 만드는 순간 아래에 블렌더 영상을 깐다.
7. 검수는 키 눌림 0.5초 구간 확대 반복 클립과 시각별 나란히 사진으로 한다.

고친 것 (표):

| 문제 | 원인 | 고침 |
|---|---|---|
| 3D로 눕힌 카드가 평평해짐 | SVG 블러 필터가 3D를 평면화 | 블러는 눕히기 전에만 |
| 뚜껑이 반대로 열림 | 경첩 회전 부호 | 회전 = 파이 - 각도 |
| 키 글자가 안 보임 | 윗면 아래에 놓아 묻힘 | 윗면 + 0.004 |
| 키 눌림이 안 보임 | 깊이가 화면에서 읽히지 않음 | 깊이 0.62, 내려감 0.05초 |

## 새 영상에 시킬 때 쓰는 지시문 예
```
이 영상에서 눌림이나 움직임이 "화면에서 읽히는지"를 숫자와 확대 클립 둘 다로 확인해 줘.
숫자가 비슷해도 화면에서 안 보이면 키워서 다시 보여 줘.
3D 장면은 카메라부터 맞춰. 원본 화면에서 기준이 되는 점 몇 개의 좌표를 찍어서 카메라 위치를 자동으로 맞춰 줘.
빠른 렌더로 구조를 먼저 보여 주고, 내가 오케이하면 최종 품질로 뽑아.
```
