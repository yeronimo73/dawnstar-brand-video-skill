# 지시문 모음

던스타가 참고 영상 여섯 편을 똑같이 만들며 클로드에게 실제로 준 지시와, 판마다 돌려받은 피드백, 그때 잰 숫자, 작업 순서를 영상별로 적어 두었다.

파일마다 같은 순서다.

1. 참고 영상 (제작자 계정 + 게시물 ID)
2. 실제 지시와 피드백 (시간순)
3. 측정 숫자
4. 작업 순서
5. 같은 일을 새 영상에 시킬 때 쓰는 지시문 예

따옴표 안의 문장은 작업 중 실제로 한 말이다. 따옴표가 없는 문장은 그때 기록을 정리한 것이다. 기록에서 확인하지 못한 값은 「확인 못 함」이라고 적었다.

| 파일 | 영상 | 한 줄 |
|---|---|---|
| oldfilm.md | 올드필름 브랜드 필름 64초 | 컷 43개, 망점 16px 30도 |
| liquid-text.md | 손가락이 만든 물에 녹는 글자 12초 | 물방울 3프레임마다, 0.45초, 초당 270px |
| motion-showreel.md | 모션 쇼릴 15초, 60fps | 점 3,200개, 오차 5.5에서 4.15 |
| template-cube.md | 웹사이트 템플릿 열 개 13초 | 391프레임 전부, 여섯 판 |
| paper-collage.md | 종이 오려 붙인 튜토리얼 61초 | 차이 지도, 첫 장면 아홉 판 |
| 3d-keyboard.md | 카드가 눕더니 3D 키보드 22초 | 키 눌림 깊이 두 배, 0.05초 |

참고 영상은 학습용이다. 원본 영상·음악·화면은 이 저장소에 들어 있지 않고, 올리는 영상에도 쓰지 않는다.
