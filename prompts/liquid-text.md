# 손가락이 만든 물에 녹는 글자

## 참고 영상
인스타그램 제작자 계정 studio.jiiwon, 게시물 ID Db1_p35TbhR. 12초 안팎, 354프레임(30fps 기준), 시연 화면과 1~3단계 해설 화면으로 구성.
손가락으로 누르면 물이 생겨 닿은 글자가 녹아내린다. 코드(바이브 코딩)로 만든 화면이다.

| 판 | 한 일 | 받은 말 |
|---|---|---|
| 시작 | 영상 링크를 건네며 | "이거 리버스엔지니어링해서 만드는방법찾아줘" |
| | | "똑같이만들어봐" |
| v1 | 입자에 응집·반발·점성을 넣고 손가락을 스프링으로. 2프레임/초 접촉표만 보고 "구조가 같다"고 보고 | "이거 레퍼런스랑 달라.. 흉내만 냈을 뿐." (비교 캡처 8장과 함께) |
| v2 | 원본 화면의 물리값을 재서 물방울 모델을 통째로 교체 | "너무 둥글 둥글 해. 왼쪽거랑 틀려.." (2단계 화면 캡처 2장과 함께) |
| v3 | 2단계 모델을 물방울별 커널의 합으로 교체 | "잘했어" |

v1에서 틀린 점: 접촉표만 보고 같다고 말했다. 캡처를 보니 덩어리가 매끈한 지렁이 모양이었다.
v2에서 틀린 점: 2단계를 넓은 가우시안 하나로 그려 동심원처럼 둥글게 나왔다.

## 측정 숫자
| 항목 | 값 |
|---|---|
| 물방울 생성 | 누르는 동안 3프레임마다 손가락 위치에 하나 |
| 물방울이 떠 있는 시간 | 0.45초 (제자리, 손가락을 따라가지 않음) |
| 낙하 | 중력이 켜지고 선형 저항으로 종단속도 270px/초 (G 675, drag 2.5) |
| 서로 당김 | 없음 (응집을 넣으면 덩어리가 뭉쳐서 틀림) |
| 입자장 | 입자를 1/4 격자에 찍고 가우시안 시그마 70 |
| 글자가 젖는 조건 | 글자 중심에서 장 값이 0.18~0.36 사이이면 젖음 |
| 물 덩어리 모양 | 젖은 글자의 굵은 모양을 시그마 10으로 번지게 한 것 + 0.12 x 장, 임계 0.10 |
| 1단계 타원 | 반지름 54, 속도 방향으로 늘이고 옆은 줄임(넓이 보존), 중심 = 위치 + 0.75 x 속도 x 0.167초 |
| 2단계 | 물방울마다 늘어난 (1-r^2)^3 커널(반지름 125)을 더한 장의 등고선 6개 (0.03, 0.3, 0.8, 1.5, 2.4, 3.5) |
| 색 | 시연 화면 색상 h = 183 + 2.65 x (f - 8), 단계 화면 h = 35 + 1.97 x (f - 290) |

## 작업 순서
1. 354프레임(원본 1080 해상도)을 전부 뽑는다.
2. 손가락이 그리는 원을 프레임마다 추적해서 위치 표를 만든다.
3. 글자 상자를 측정한다.
4. 화면 속 디버그 화면(1~3단계)에서 물리값을 읽는다. 물방울이 생기는 주기, 떠 있는 시간, 낙하 속도.
5. 물 덩어리는 어떤 모양을 따라 생기는지 본다. 젖어서 굵어진 글자 모양을 따라 생긴다는 것을 찾았다. 그래서 테두리가 글자 모양대로 울퉁불퉁하고, 띄어쓰기 자리에 구멍이 남는다.
6. 장면 네 가지(최종, 1단계, 2단계, 3단계)를 각각 맞춘다.
7. 판마다 원본|재현 나란히 사진으로 확인한다.

```
화면에 디버그 표시가 있으면 그것을 구현 단서로 써.

```
